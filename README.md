# Shree Engineers Corporate Website

Official corporate website for **Shree Engineers** — specializing in Heavy Industrial Design Engineering and Modern Digital Enterprise Solutions.

---

## 🏗️ Core Engineering Verticals
- **AutoCAD 2D & 3D Design**: Precision fabrication shop drawings, GA layouts, and BOM generation.
- **Mechanical Equipment Design**:
  - Pressure Vessels (ASME Section VIII Div 1 & 2)
  - Heat Exchangers [Shell & Tube] (TEMA Class R, C, B & ASME)
  - Storage Tanks (API 650 & API 620)
- **Mechanical Machine Design & Component Design**: Kinematic modeling, custom automation, and DFMA.
- **Civil & Structural Design**: Industrial pipe racks, technological structures, and equipment foundations (AISC / IS 800).
- **Piping Design Works & AVEVA E3D**: 3D plant modeling, isometric extraction, MTO, and CAESAR II stress analysis.

## 📁 Repository Structure

### 1. Plain HTML / CSS / JS Version (`/plain-website`)
Located in the [`plain-website/`](./plain-website/) directory:
- `index.html`: Fully standalone responsive webpage with Tailwind CSS CDN, Lucide Icons, and Google Fonts.
- `style.css`: Clean CAD blueprint background patterns and custom interactive styling.
- `script.js`: Interactive tab switcher for engineering services, tech stack filtering, quotation modal, and WhatsApp message generator.

> **Zero installation required**: Simply double-click `plain-website/index.html` to open it in any browser!

### 2. React + Vite + Tailwind Version
The root directory contains the full modern React application:
- `npm install`
- `npm run dev` (Runs Vite dev server)
- `npm run build` (Generates production build in `dist/`)
